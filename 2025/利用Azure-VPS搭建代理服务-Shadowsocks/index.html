1. 创建Linux虚拟机

在Azure上创建一个Linux虚拟机，我这里选择的映像是Ubuntu22.04，具体操作这里不在赘述，可以参考这篇知乎文章，我的区域选择在了East US，当初本意是为了使用Gemini。

2. 连接到虚拟机并安装代理服务

获取公网ip，并进入虚拟机

  • 部署完成后，在虚拟机概览页面找到“公共ip地址”，可以通过windows命令进入。（可以参考我下面的步骤直接复制命令，或者按上面的知乎文章输命令进入，都是一样的）

​ 进入该选项中，选择编辑配置，将刚保存到~/.ssh 文件中的密钥路径填入，然后直接复制该命令进入虚拟机

  • 更新系统

    sudo apt update && sudo apt upgrade -y

  • 安装代理服务（以 Shadowsocks-libev 为例）

    sudo apt install shadowsocks-libev -y

  • 编辑配置文件

    sudo nano /etc/shadowsocks-libev/config.json，注意：需要将里面原本的配置删除

    接着将这段复制进去

    注意：配置完后重启shadowsocks sudo systemctl restart shadowsocks-libev

  • 设置开机自启动

    sudo systemctl start shadowsocks-libev sudo systemctl enable shadowsocks-libev

  • 开放防火墙端口

    • 回到 Azure 门户 → 虚拟机 → “网络” → “入站端口规则”
    • 添加规则：允许 TCP 端口 8388（或你设置的端口）

  • 检验

    • 输入ss -tuln | grep 8388检查监听端口

      出现LISTEN 0 128 0.0.0.0:8388 0.0.0.0:*，如果显示127.0.0.1:8388可能是你的json文件sever写错了，或者是你没有重新启动shadowsocks。

    • 在本地windows powershell中输入Test-NetConnection ‘你的公网ip' -Port 8388

      出现TcpTestSucceeded : True就是成功了。

本地配置Shadowsocks

  1. 下载客户端
    • Windows：Shadowsocks-Windows
    • macOS：ShadowsocksX-NG
    • Android：Shadowsocks
  2. 配置服务器信息
    • 服务器 IP：你的 Azure 公网 IP（如 20.123.45.67）
    • 端口：8388
    • 密码：你在 config.json 中设置的密码
    • 加密方式：chacha20-ietf-poly1305
  3. 启用系统代理（或使用 PAC 模式）
    • 启动后，浏览器或系统流量将通过代理。小飞机变成蓝色证明已经成功。
